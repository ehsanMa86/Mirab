!!! info "About this page"
    Mirab runs [SWMM5+](https://github.com/CIMM-ORG/SWMM5plus) through [swmm5plus-capi](https://github.com/ehsanMa86/swmm5plus-capi), which builds SWMM5+ as a shared library with a small C interface (`include/swmm5plus.h`) that applications in any language can load. This reference comes from that project. To install SWMM5+ for Mirab, see [Installing SWMM5+](engines.md#installing-swmm5).
